# Сайт ЛМБ (Литой Модифицированный Бетон)

Одностраничный сайт-визитка компании ЛМБ: товарный и литой модифицированный бетон
с доставкой в г. Алматы. Сайт на чистом HTML/CSS/JS, без сборки и зависимостей —
достаточно открыть `index.html` в браузере или разместить на любом статическом хостинге.

## Структура проекта

```
site/
├── index.html      — вся страница (разметка, стили, скрипты, переводы на 5 языков)
└── assets/         — фотографии, логотипы партнёров и логотип ЛМБ
```

Один файл `index.html` содержит всё: секции сайта, переключатель языков
(RU / EN / KK / TR / ZH), форму заявки с отправкой в WhatsApp и плавающую кнопку связи.

## Деплой на GitHub Pages

### 1. Создайте репозиторий на GitHub

Зайдите на [github.com/new](https://github.com/new) и создайте новый репозиторий
(например, `lmb-site`). Ничего не инициализируйте (без README/.gitignore — они уже есть здесь).

### 2. Загрузите файлы этой папки в репозиторий

Откройте терминал внутри папки `site` и выполните:

```bash
git init
git add .
git commit -m "Initial site version"
git branch -M main
git remote add origin https://github.com/<ваш-логин>/<название-репозитория>.git
git push -u origin main
```

Замените `<ваш-логин>` и `<название-репозитория>` на свои значения.

### 3. Включите GitHub Pages

1. Откройте репозиторий на GitHub → вкладка **Settings**.
2. В меню слева выберите **Pages**.
3. В разделе **Build and deployment → Source** выберите **Deploy from a branch**.
4. В **Branch** выберите `main` и папку `/ (root)`, нажмите **Save**.
5. Через 1–2 минуты сайт будет доступен по адресу:
   `https://<ваш-логин>.github.io/<название-репозитория>/`

Никакой сборки не требуется — GitHub Pages отдаёт `index.html` как есть.

### Обновление сайта после деплоя

После любых правок в файле повторяйте:

```bash
git add .
git commit -m "Описание изменений"
git push
```

Изменения на сайте появятся автоматически в течение 1–2 минут.

## Возможные доработки

- **Форма заявки** сейчас отправляет данные в WhatsApp (`+7 778 124 02 98`). Если нужна
  отправка на почту или в Telegram — потребуется подключить сторонний сервис форм
  (например, Formspree или Web3Forms) или бота.
- **Собственный домен**: во вкладке Settings → Pages есть поле Custom domain — впишите
  свой домен и настройте DNS-запись согласно подсказке GitHub.
